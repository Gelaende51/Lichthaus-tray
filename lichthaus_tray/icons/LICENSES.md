# Icons

`on.svg`, `off.svg` and `disconnected.svg` are the `lighthouse` set, the
default icon set of the Plasma widget
([Lichthaus-plasma](https://github.com/Gelaende51/Lichthaus-plasma),
`package/contents/icons/lighthouse/`), copied unchanged.

| Set | Source | Author | Licence | Files |
|---|---|---|---|---|
| `lighthouse` | Lichthaus | Lichthaus contributors | AGPL-3.0 (as the project, see [LICENSE](../../LICENSE)) | all three |

They carry Plasma's `current-color-scheme` stylesheet; the tray replaces
the colour with the desktop palette's text colour when it draws them.
